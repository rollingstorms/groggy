# Reusable release CI evidence — 2026-11-27

Completed support work within existing 34.2 and AR7.11; no stable checklist row
is added or closed by this tooling change.

`notes/scripts/summarize_release_ci.py` validates downloaded manual CI metadata,
20 artifact receipts and the completed run log against a pinned local runtime.
It rejects incomplete/failed/duplicate/missing jobs, an executed publish job,
missing or mislabeled artifacts, invalid hashes, version disagreement, incomplete
native suite evidence and source/configuration mismatches. Existing reports are
never overwritten. It performs no network requests, workflow dispatch or publish.

Seventeen tests in `tests/tooling/test_release_ci_summary.py` use the previously
recorded real flow candidate as evidence fixtures. The collector also passes on
actual [run 45652492406](https://github.com/rollingstorms/groggy/actions/runs/45652492406),
recording all 21 required successes, skipped publication, 19 wheel combinations
and source rebuilding in the [new CI receipt](../benchmarks/normalization-safety-ci-qualification-2026-11-27.json).

The run is anchored to candidate `ac59fcf1d5fc74efe9134a1ae73a19c2185507c3`; its
500 production source files are byte-equivalent to locally qualified runtime
`6ec32ed1959543036f638abedf0dbe23df21a6f7`. Newer source changes do not inherit this
qualification. Linux Python 3.12 runs the maintained full Python/docs suite;
other wheels run ownership/application checks, and the source rebuild runs smoke.

Tracked manifests match the local receipt. Cargo lockfiles are ignored and
regenerated by CI, so dependency-lock identity is not claimed. Collected JSON
receipts are trusted CI output, not independent wheel downloads or an attestation
service. All supplied metadata/artifacts/logs must come from the same run.

## Reproduce

After the run completes, save `gh run view ID --json databaseId,headSha,event,status,conclusion,url,jobs`
and `gh run view ID --log`, and download `qualification-*` artifacts with the
GitHub CLI. Then supply those paths to:

```sh
python notes/scripts/summarize_release_ci.py \
  --run /tmp/run.json --artifacts /tmp/qualification \
  --log /tmp/run.log \
  --local-receipt notes/benchmarks/normalization-safety-local-qualification-2026-11-25.json \
  --output /tmp/new-ci-receipt.json
```

Use a fresh output path. Validate the tool with
`python -m pytest tests/tooling/test_release_ci_summary.py -q`.
